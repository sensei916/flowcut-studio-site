# FlowCut Studio 官网

FlowCut Studio 是一个 AI 无限画布工作台。这个仓库包含发布到 GitHub Pages 的官方网站。

- [官方网站](https://sensei916.github.io/flowcut-studio-site/)
- [打开工作台](https://flowcut-workbench.postprep.workers.dev/workbench/)
- [下载 Android APK](https://flowcut-workbench.postprep.workers.dev/android/FlowCut.apk)

网站使用静态 HTML 和 CSS，通过 `main` 分支根目录发布。在本地可打开 `index.html`，或运行 `python -m http.server 8000` 预览。

工作台和安装包由 FlowCut 的 Cloudflare 部署提供。
