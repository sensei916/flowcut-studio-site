# FlowCut Studio 官网

FlowCut Studio 是一个 AI 无限画布工作台。你可以在同一个项目里整理提示词、分镜文案、图片和动效，用节点与连线保留创作过程，再把可用的成品导出。

- [官方网站](https://sensei916.github.io/flowcut-studio-site/)
- [打开工作台](https://flowcut-workbench.postprep.workers.dev/workbench/)
- [下载 Android APK](https://flowcut-workbench.postprep.workers.dev/android/FlowCut.apk)

## 可以用它做什么

| 功能 | 使用方式 |
| --- | --- |
| 无限画布 | 创建空白项目，拖动节点、平移缩放、连接不同阶段的结果。支持分支的模板节点可以续写、换风格或作方案对比。 |
| 文本与规划 | 在输入栏选择「文本模型」。文本、规划、执行模式可用来撰写内容、拆分镜头、起草脚本或生成代码。推理等级和输出上限按所选模型配置。 |
| AI 生图 | 在输入栏切换「生图模型」，填写画面描述。支持多图的模型可以选择生成数量，结果会出现在画布节点上。 |
| 本地模板 | 内置科普动效、杂志封面、商家 H5、歌词 MV、战术 HUD、粒子可视化六种模板，打开卡片即可试用。 |
| 保存与分享 | 保存原图、复制文本，或将画布成品导出为 HTML。支持录制的模板可以导出视频。同款口令可分享提示词和布局。 |

## 第一次使用

1. 进入网页版，或从官网下载并安装 Android APK。
2. 从「空白画布」开始，或先用一张本地模板体验节点与导出。
3. 需要云端模型时，从顶部用邮箱或手机号加密码注册或登录。在账号面板兑换积分，再从底部选择模型和参数。
4. 例如输入「把夜市的一晚拆成 3 幕短视频分镜」，用文本模型生成规划。随后切换到生图模型，为分镜做一张封面。
5. 在画布上排列分镜和图片。点图片节点保存原图，或从顶部导出画布成品。

## 账号、积分和项目保存

- 空白画布与本地模板可直接使用。云端模型和积分兑换需要登录。
- 新账号从 0 积分开始。不同云端模型按图片数量或实际 Token 用量结算。任务失败会退回预留积分。
- 账号可跨设备登录使用积分。项目和创作结果保存在当前浏览器或应用，换设备前可导出作品。

## 官网前端

此公开仓库维护官网前端和静态素材。工作台与 APK 下载通过页面链接使用现有线上服务。

- [index.html](index.html) 包含页面结构、功能介绍、上手步骤与常见问题。
- [styles.css](styles.css) 包含主题和响应式样式。
- [assets/](assets/) 保存品牌图标和工作台预览图。

本地可直接打开 `index.html`，或运行 `python -m http.server 8000` 后访问 `http://localhost:8000/`。GitHub Pages 从 `main` 分支的仓库根目录发布静态文件。
